Cloudflare Pages & Workers Deployment

Configure these Environment Variables / Secrets in your Cloudflare dashboard or wrangler.toml.

Variable Type Default Purpose
PAT_1, PAT_2, ... Secret - GitHub Personal Access Tokens rotated automatically when rate limits hit.
GITHUB_USERNAME Variable machfudn Default username fallback when username query parameter is omitted.
README_THEME Variable transparent Default theme fallback when theme query parameter is omitted.
README_LOCALE Variable en Default card language fallback when locale query parameter is omitted.
README_INCLUDE_ALL_COMMITS Variable true Count all lifetime commits by default when include_all_commits is omitted.
README_LANGS_COUNT Variable 8 Default number of languages shown on top-langs when langs_count is omitted.
CACHE_SECONDS Variable 3600 Custom CDN cache lifetime in seconds.
WHITELIST Variable - Comma-separated list of allowed GitHub usernames.
GIST_WHITELIST Variable - Comma-separated list of allowed Gist IDs.
EXCLUDE_REPO Variable - Comma-separated repository names excluded globally from card stats.
FETCH_MULTI_PAGE_STARS Variable false Enable multi-page GraphQL star fetching for accounts with over 100 repositories.
