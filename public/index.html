GitHub Readme Stats

Powered by Hono & TypeScript on Cloudflare Pages

Swagger UI Documentation OpenAPI JSON Original Project

API Endpoints

  • GET /api?username=:username — Generate stats card
  • GET /api/pin?username=:user&repo=:repo — Generate repository pin card
  • GET /api/top-langs?username=:username — Generate top languages card
  • GET /api/wakatime?username=:username — Generate WakaTime stats card
  • GET /api/gist?id=:gist_id — Generate Gist card
  • GET /api/status/up — Personal Access Token (PAT) health check
  • GET /api/status/pat-info — Detailed PAT diagnostics
  • GET /ui — Interactive Swagger UI documentation

Cloudflare Pages Deployment

Configure the following Environment Variables / Secrets in Cloudflare Pages dashboard:

  • PAT_1, PAT_2, etc. — GitHub Personal Access Tokens (automatically rotated on rate limit)
  • CACHE_SECONDS — Custom CDN cache time (optional)
  • WHITELIST — Restrict allowed usernames (optional)
  • EXCLUDE_REPO — Repositories to exclude from stats (optional)
