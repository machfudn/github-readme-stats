# Test Files Rule

All test files MUST be placed in `tests/` folder.
NEVER create test files in root or other directories.

# Language Rule

All new code and test files MUST be written in TypeScript (`.ts`).
NEVER create new files in JavaScript (`.js`).

# Directory Structure Rule

Always organize and place code matching the existing directory structure for easy maintenance.
Reuse existing directories that serve the same purpose (e.g., `src/fetchers/`, `src/cards/`, `api/`, `tests/`).
NEVER create redundant or extra directories if an existing one already fits the purpose, unless the scope or requirement is genuinely different.
